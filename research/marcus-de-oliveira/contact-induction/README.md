# Contacts plus one-coordinate reduction: where an induction n−1 → n stops

- **Task:** `mdo-contact-induction`. Agent `claude-opus-5-5-induction` (GitHub owner `Raghavsk24`). November 27, 2026.
- **Status: partial, with a precise obstruction.** Lemmas 1–4 are complete written proofs (PROVED). The n = 3 computations are EXACT (Gaussian rationals). **Not independently reviewed.** This is not a claim about MDO for n ≥ 4.
- **Inputs:** the reviewed contact reduction ([statement](../n5-contact-program/contact-reduction/README.md), [review](../contact-reduction-review/README.md)), [pointwise gluing](../pointwise-gluing/README.md), [pole compression](../pole-compression/README.md), the [normal pole step](../normal-pole-step/README.md), [Hermitian lifting](../hermitian-lifting/README.md) and the [n = 5 strata census](../n5-contact-program/strata/README.md).

## Answer in one paragraph

A rigid contact configuration forces reducible structure in U only through squared minors. If the contact set T is *automatic*, the support gap equals a nonnegative combination of squared minors of U. Then touching the supporting line forces those minors to vanish, and no violation is possible (Lemma 2). At n = 3 every possible contact set is automatic and of rectangle type. Touching is then exactly U_kl = 0, which triggers both gluing and the normal pole step (Theorem 3). So at n = 3 the contact reduction alone proves MDO for every unitary, and the induction step works. For n ≥ 4 the chain breaks twice. First, a single vanishing minor or entry triggers none of the four repository reductions (Lemma 4). Second, contact sets need not be automatic: 90 of 214 orbits of six-sets at n = 4, and every exactly tested 8-set at n = 5. For a non-automatic set the gap is not a sum of squared minors, so contacts with stationarity give no vanishing minor to work with. Stationarity in U comes free (Lemma 1), but it adds only the Hermitian condition below, which no reduction uses for normal A.

## Setting

Write z_σ = ∏ᵢ(aᵢ + b_σ(i)), d_U = det(D_a + U D_b U*) = Σ_σ μ_σ(U) z_σ and x = θz. The contact set T, the gaps g_σ = x_σ − x_π, L_U(x) = Σ_σ μ_σ(U) Re g_σ, the variety X and the slice Λ(x) are as in the contact reduction. A violation means L_U(x) < 0. *Touching* means L_U(x) = 0. A squared-minor vector is m_{K,J} = (1[σ(K) = J])_σ, and Lemma 1(a) there gives ⟨μ(U), m_{K,J}⟩ = |det U[K,J]|².

## Lemma 1 (stationarity is free; PROVED)

If MDO fails for some U at some spectra, then there are spectra (a′, b′) and U* with the following properties. The contact set T has |T| ≥ 2n − 2 and x′ is isolated in X ∩ Λ(x′). U* minimizes U ↦ Re(θ d_U(a′, b′)) over U(n), and L_{U*}(x′) < 0. In particular θ[B′, adj M] is Hermitian, where B′ = U* D_b′ U*^* and M = D_a′ + B′.

*Proof.* Apply Theorem A(b) of the contact reduction to μ(U). X, Λ(x′), T(x′) and the isolation property depend only on x′, not on μ. So minimizing over the compact group U(n) at fixed x′ keeps every property and can only decrease L. For the first-order condition, differentiate along U ↦ e^{tK}U* with K skew-Hermitian. This gives Re(θ tr(adj(M)[K, B′])) = Re tr(θ[B′, adj M] K) = 0 for every K, which is equivalent to Hermiticity. ∎

The first step of [Hermitian lifting](../hermitian-lifting/README.md) is the same extremal choice. Its Lemma E turns this condition into a real relation ℓ(D₁) = ℓ(det M)·v*(A+β)⁻¹v. That relation needs A Hermitian. For normal A the factor v*(A+β)⁻¹v is complex and rotates the supporting direction, so the condition alone gives no reduced inequality.

## Lemma 2 (automatic strata: touching forces vanishing minors; PROVED)

Suppose T(x) = T and the gap cone N_T is generated by squared-minor vectors. By §6 of the contact reduction, the gap vector Re g(x) lies in N_T. Then Re g(x) = Σ_k c_k m_{K_k,J_k}, with c_k ≥ 0 and no σ ∈ T satisfying σ(K_k) = J_k, and for **every** U ∈ U(n)

  L_U(x) = Σ_k c_k |det U[K_k, J_k]|² ≥ 0.

So the configuration admits no violation. Touching holds exactly when det U[K_k, J_k] = 0 for every k with c_k > 0. *Proof:* pair Re g with μ(U) and apply Lemma 1(a) of the contact reduction. ∎

## Theorem 3 (n = 3: the induction step works; PROVED, replayed EXACT)

Let n = 3 and let a supporting line contain z_σ for |T| ≥ 4 permutations.

(a) For each n ≥ 3, Σ_σ sgn(σ) x_σ = det([vᵢ, wⱼ]) = 0 on X, because the bracket matrix has rank ≤ 2. More generally, for every 3-sets K, J and bijection ρ : Kᶜ → Jᶜ, the six permutations extending ρ satisfy Σ_{τ: K→J} sgn(τ) x_{τ∪ρ} = 0 (*hexagon relation*). Since Σ sgn = 0, the same relation holds for the gaps. Its real part reads Σ_{σ∉T} sgn(σ) Re g_σ = 0.

(b) At n = 3, either |T| = 6 (then L ≡ 0), or T = {σ : σ(k) ≠ l} for some k, l (*rectangle type*). The other 4-sets miss two permutations of equal sign, and Re g > 0 on both contradicts (a). A 5-set misses one permutation, which (a) forces to have zero real gap.

(c) For the rectangle type, the two non-contacts σ₁, σ₂ have σ(k) = l and opposite signs. By (a), Re g_{σ₁} = Re g_{σ₂} =: γ > 0, and for every U ∈ U(3)

  Re(θ d_U) = m + |U_kl|² γ.

(d) Hence, at n = 3, the contact reduction plus (c) proves MDO for every unitary. MDO(3) itself is known; the point is that this route works. Touching happens exactly when U_kl = 0. That is a zero rectangle with |R| + |L| = 1 + 1 = n − 1, so [pointwise gluing](../pointwise-gluing/README.md) applies. Column l then sees only two eigenvalues of A, and together with −b_l these three points always lie on a generalized circle. So the [normal pole step](../normal-pole-step/README.md) at b_l is also available, and likewise in the row version.

**Exact replay** ([`replay_exact.py`](replay_exact.py), output in [`replay_exact_output.txt`](replay_exact_output.txt), under a second). It checks the following:
- the relation in (a) at 20 random spectra;
- an explicit exact rigid configuration a = (−2+2i, −2+3i, −48/17 − 12i/17), b = (−i, −3, 3+i), θ = −7/6 + i. It has exactly 4 contacts on Re(θw) = −80 (rectangle type, k = l = 3) and noncollinear distinct spectra. The infinitesimal rigidity rank is 4 = 2n − 2;
- the identity (c) for 5 exact Cayley unitaries with Gaussian-rational entries.

A seeded search of 20,000 random contact patterns found no non-rectangle 4-set, as (b) predicts.

## Lemma 4 (why n ≥ 4 breaks; PROVED)

Let n ≥ 4 and suppose the only reducible structure available is a vanishing minor, for example U_kl = 0, as Lemma 2 provides.
- **Gluing** needs U[R, L] = 0 with |R| + |L| = n − 1 and R, L nonempty (after permuting coordinates). That is at least n − 2 ≥ 2 zero entries forming a rectangle. A single zero entry, or a vanishing k×k minor with nonzero entries, is not one.
- **Normal pole step** at b_l needs the active eigenvalues {aᵢ : U_il ≠ 0} and −b_l to lie on one generalized circle. With U_kl = 0 that is n ≥ 4 points, which imposes n − 3 ≥ 1 real conditions on the spectra. The contact conditions are |T| − 1 real equalities in Re x, and they do not imply concyclicity. The same holds for the row version.
- **Hermitian lifting** and the circular pole variant need a collinear or concyclic spectrum, which is a condition on (a, b) independent of U and of T.

So for n ≥ 4 a vanishing minor gives no one-coordinate reduction. More fundamentally, Lemma 2 applies only to automatic T. The [strata census](../n5-contact-program/strata/README.md) finds 90 of 214 orbits of six-sets non-automatic at n = 4. At n = 5, all 9 exactly tested 8-sets are non-automatic, and conjecturally all are. For a non-automatic T the gap pairs μ(U) with a generator of a non-minor facet. No sign or vanishing statement about minors of U follows from contacts or from Lemma 1.

**Precise obstruction.** An induction n−1 → n built from rigid contacts and one coordinate needs, in each non-automatic stratum, a new inequality of the form ⟨μ(U), p⟩ ≥ 0 for the non-minor gap generators p. Equivalently, for n = 5, the non-minor facets of Q₅ must be handled one by one. Neither the contact reduction, nor first-order stationarity, nor any of the four reductions supplies such an inequality. At n = 3 none is needed, because every stratum is automatic and of rectangle type.

## Failed approaches and checks not done

- *Numerical stationarity test at n = 3:* 300 BFGS starts over U(3) at the rect configuration found only the value m, on the face U_33 = 0. This is explained exactly by (c), so the script was dropped.
- *Exact non-automatic n = 4 example:* not built. The linear trick used here (x is C-linear in one vector v_n) gives 4 real unknowns, while 6 contacts at n = 4 need 5 equations. Two free vectors make the system bilinear. A next agent could solve it with one quadratic, or numerically, and then search for a touching U with all minors nonzero.
- Second-order conditions were not used. In automatic strata they are not needed, and in non-automatic ones it is not known what they give.

## Next decision

The obstruction moves the n = 5 burden to non-minor gap generators. The useful next step is a single non-automatic rigid six-set at n = 4 (from the census). For it, either show that touching U must have a zero rectangle of perimeter n − 1, or exhibit a touching U with all minors and all pole defects nonzero. The second outcome would make the obstruction concrete at n = 4.
