## A. Statements

**Theorem 1 (p. 1).** In paper notation: let T = {1, 5, 6, 9, 14, 18} (0-based lexicographic indices). For every x in X and reference permutation pi* in T with P c(x) >= 0 and (P c(x))_pi = 0 for all pi in T, Phi_{c(x)}(O) >= 0 for every O in SO(4) (equivalently O(4)). The contacts are non-strict, so extra contacts are allowed. All spectra are included: repeated eigenvalues, a_i + b_j = 0, and the "full-complex-equal" locus.
- T equals Appendix E's T_90 literally, so no group element is needed (EXACT).
- The statement is (*) for T_90 at full strength, provided "spectrally realizable" is read as "x in X". By the paper's Section 3, every nonzero x in X has a finite spectral representation, so the two readings agree (CITED).

**Lemma 2 (p. 3).** Let x be a strict point: all 18 off-T gaps > 0, real d > 0, normalized so that E = F_5 - F_1 = 1. Then there is an irreducible algebraic curve in X through x on which the five complex differences F_i - F_1 (i in T) stay constant. At least one anchored coordinate F_sigma - F_1 is nonconstant on its normalization.

**Lemma 3 (pp. 4-5).** Take real r, L0, B0, Af, Ag and complex a, b, d with 2(d+r)b = ra - d^2 + L0 d + B0. Suppose y = Im d != 0 and Im a / y, Im b / y lie in fixed bounded intervals. Then |b| <= C(1+|d|) and |ra| <= C(1+|d|^2). If moreover f + g + d = (-(r-u+1) ra + P2(d)) / (2(d+Af)(d+Ag)) with deg P2 <= 2 and real coefficients, then f + g + d stays bounded as |d| -> infinity.

## D. Falsification

Two tests were run (NUMERIC; see the output file).

(a) Coordinate alignment on actual matching vectors. I took 30 random points of X (seed 2026; random spectra a, b in C^4 and a phase alpha), each solving the five real contact equations Re(F_i - F_1) = 0 for i in T by least squares. Positivity was not imposed, because the identities hold on all of X. At all 30 points:
- E is purely imaginary (max |Re E|/|E| = 5e-11);
- the H_i are real (max |Im H_i| = 1e-9);
- the affine form (6) reproduces the point (relative residual 9e-12);
- the formulas (8) hold (relative error 2e-11) and so does (10) (1.5e-13);
- the real coefficients -η Im w equal the real gaps at 17,15,11,7,4,12,0 (relative error 4e-13).

This confirms the document's coordinates are the paper's.

(b) Main statement, brief. The lib stratum search with margin 1e-2 (contact set exactly T) found no point in 12 seeds × 10 tries, which says nothing about whether the stratum is empty. With margin 0 it found 4 points (seeds 0..3) whose contact sets contain T. The worst min over SO(4) of Phi (6 BFGS restarts) was -6.3e-15, which is zero up to rounding. No violation.
