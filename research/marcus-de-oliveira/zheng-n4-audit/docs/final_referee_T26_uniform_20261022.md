## A. Statements

**Theorem 1 (p. 1).** Let T = {2,3,4,7,8,12} (0-based lexicographic indices). For every x in X and every reference permutation, if P c(x) >= 0 and (P c(x))_pi = 0 for all pi in T, then Phi_{c(x)}(O) >= 0 for every O in SO(4). The contacts are non-strict (any additional contacts are allowed). Spectra are arbitrary: repeated eigenvalues, a_i + b_j = 0 and so on are all included, because the argument uses only x in X.
- Contact set check (EXACT): T is exactly the paper's T_27 of Appendix E (identity group element), so this is (*) for T_27 with full strength.

**Lemma 1 (p. 2).** Let a cost g in V_R have a representation (4) g = q f0 + p f2 + j f5 + c f6 + e f53 + d f54 + b f55 + a f67 with all coefficients >= 0 and d > 0. If g = c(x) for some x in X, then pj >= d^2 or K := ab(e-d) - d^2(a+b+e+d) >= 0.

Inputs (1) and (2), stated for ARBITRARY nonnegative coefficients (pointwise inequalities in O, no realizability):
- (1) Phi_{p f2 + j f5 + d f54}(O) >= 0 for all O when p, j, d >= 0 and pj >= d^2.
- (2) Phi_{a f67 + b f55 + e f53 + d f54}(O) >= 0 when a, b, e, d >= 0 and ab(e-d) >= d^2(a+b+e+d).

## D. Falsification

- NUMERIC, Lemma 1 sign claim: 2000 random points (seed 1) with pj < 1 = d^2 and K < 0, about a quarter of the coordinates set to zero. min G6 = 1.108 > 0.
- NUMERIC, cited (1) on pj = d^2 and cited (2) on its boundary: 30 samples each, 12 BFGS restarts. Worst min Phi / max gap = 1e-16 and 1.6e-16, i.e. tight and nonnegative.
- NUMERIC, main statement: 8 stratum points for T_27. Worst min Phi / max gap = -3.4e-15 (round-off).
- No violation was found.

## E. Verdict

The radial-necessity argument is complete as written: it needs only X in Sing C and covers every spectrum. The proof rests on the cited pointwise capacities (1) and (2) and on paper Lemma 4.2.
