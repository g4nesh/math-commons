## Deviations and limits

- The supplement's companion script was not run or read for formulas; all identities were rebuilt from the paper's definitions with `lib/moc4lib.py` (generators, P, cubic C of (A.2)).
- The supplement's "F" (the real fourteen-variable matching cubic) is taken to be the paper's C of (A.2). Our replay of identity (2) with the paper's C gives ratio exactly 1, so the identification is consistent.
- Numeric falsification: the library stratum search returned only points with coincident labels (40/40 had minimum label separation below 1e-4). We found no eight-distinct point on the T_21 stratum; the eight-distinct claim was therefore not falsification-tested directly, only through its exact proof.

## D. Falsification

40 library stratum points (seeds 0-39, pi* = 0): worst min Phi over SO(4) = -1.5e-10 (10 BFGS restarts), max relative detector delta = 1.8e-10 (consistent with delta <= 0). All points had coincident labels, so they test the collision layer (App. B), not the eight-distinct argument. A margin-constrained search (seeds 0-9, margin 1e-2) found no point with contact set exactly T_21. No violation found.

## E. Verdict

confirmed-modulo-citations. Citations: paper App. B (Thm B.1, Lemma B.2) for collisions, Thm 1.2 for the unitary step, A.1 (X in Sing C, replayed in lib). No gap. Presentation note: the "common finite chart / projective covariance" remark is superfluous, since the paper's representation already has finite spectra.
