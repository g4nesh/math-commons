## 2. The proof-read steps, re-examined after the replay

- **Strict base.** The four functions are polynomials in (a, b, c, q) and continuous in (a, b, c), because L_e and L_p are maxima of continuous functions. They are >= 0 on dense subsets of the chambers, hence on the closed region. With x, y, z >= 0, Le e < 1 and Lp p < 1, the identity in row 3 gives G6 >= g00 (1-Le e)(1-Lp p). Then k0 = C G6 >= 1 * 1 * (1-Le e)(1-Lp p) > 0 on the whole hard region, boundary included. PROOF-READ, confirmed.
- **Domain cover for g40.** In the region ab < 1 we have L_e = 0. Rows 1-3 cover it: a,b <= 1 gives a in [z^2, 1) with z = sqrt(ab); a >= 1 gives a = 1+A; b >= 1 is symmetric, and these exhaust the cases since ab < 1 rules out a, b > 1 together. Within each row, ac < 1 has p free, and ac > 1 takes p < P_ac, because p >= P_ac is the cited (0,7,12,40) capacity. Row 7 covers ab > 1, ac < 1 and e < E_ab. Row 8 covers ab >= 1, ac >= 1, p < P_ac and e < E_{r0}: U >= 0 sweeps p over [0, P_ac) monotonically, and E sweeps e over [0, E_{r0}). The cited allocation lemma covers e >= E_{r0}, and the core capacity covers e >= E_ab. The case e = 0 is separate: there G40 = k0 + k1 j with k1 >= 0. The boundaries ab = 1, ac = 1, a = 0, b = 0, c = 0 and q = 0 are limits of the charts. There the two non-strict inequalities pass to the limit, because each row's endpoint J depends continuously on the original variables. The limiting endpoint is still a sufficient capacity, because the set of costs satisfying the support inequality is closed. The strict k0 bound holds everywhere. PROOF-READ, confirmed.
- **Bernstein.** k0 > 0, 2k0 + J k1 >= 0 and G40(J) >= 0 give G40 > 0 for 0 <= j < J. The multipliers d0 and prod den^deg are positive, and n has nonnegative coefficients and is nonzero. PROOF-READ, confirmed.
- **KKT chart coverage** (argument checked by the auditor; the document only names the charts). For b, c, p, q > 0 the energy is minimized at an interior point. Its minimizer satisfies delta_i = min(p_i/2, beta_i), because -delta + delta^2/p is minimized on [0, beta] at min(p/2, beta). The reduced function f(beta_1) is C^1 and strictly convex, with f'(0+) < 0 and f'(1-) > 0, so it has a unique stationary beta_1 in (0, 1). Whichever pattern holds there (H: p_i/2 < beta_i; C: p_i/2 >= beta_i; for CC, which of p/(2 beta_1) and q/(2 beta_2) is larger), the chart parameters can be solved for: theta = beta_1, L = theta/b, U and W from p and q (both >= 0), and the remaining resource from stationarity. Row 9 shows exactly this stationarity. So every (b, c, p, q) > 0 lies in some chart. In any case each chart J is the energy of a feasible point, so it is >= the true minimum. Positivity on [0, J_chart) therefore covers [0, J), and optimality is not even needed. PROOF-READ, confirmed.
- **SOC peeling.** Nonnegative Y-coefficients give (1+Y)^2 L0 >= L0|_{a=0} >= 1, that is L0 >= (1 - a/J)^2. They also give B1, B2 >= 0 on 0 <= a < J. With S = s/(1-as) >= 0 for as < 1, the identity in row 11 gives G70 >= (1-as)^2 (1-a/J)^2 > 0. The cited old SOC covers as >= 1, and the cited capacity covers a >= J. Zero b or c is handled by the document's epsilon-perturbation argument (J_eps increases to J): p, q = 0 already lie in the HH/HC charts (U = 0 or W = 0), and the limit keeps the strict quantitative bound. PROOF-READ, confirmed.
- **Note on scope (not a certificate; CITED).** The step "a spectrally realizable hard cost must satisfy G = 0" (p. 2) is clear when c + t kappa lies in X for some real t. For a point x of X with C = 0 and grad C = 0, Euler's identity gives Hess C(x) x = 0, so det Hess = 0. But c(x) = Re(x - F kappa) is not of that form when x has an imaginary part outside R kappa. The document relies here on its cited "spectrally realizable radial necessity, with their existing complex-spectral limiting scope" (p. 1). The first audit's remark (section A) that the argument "covers all spectra" because x is in X therefore holds only modulo that cited lemma. This should be checked wherever that lemma is audited.
