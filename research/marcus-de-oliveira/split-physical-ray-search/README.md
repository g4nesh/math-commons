# Bounded physical search on the 35 remaining split-pattern ray classes

**No negative physical ray was found in this finite search.** All 35 orbit
representatives not settled by the coefficient-row or coarsening arguments of
[PR108](https://github.com/g4nesh/math-commons/pull/108) were optimized from four
deterministic starts, for 140 completed runs. The best endpoint per class was
then quantized through a rational Cayley chart: all 35 resulting exactly
unitary Gaussian-rational matrices have strictly positive exact ray values.

This is bounded numerical evidence plus 35 exact finite evaluations. It is
**not** a proof that any of the 35 functions is universally nonnegative, nor
that the optimizer reached global minima. The exact reconstructed matrices
are close to, but not identical to, the floating endpoints; their positive
signs do not certify the signs of those original floating matrices.

## Reproduce the finite exact evidence

From the repository root, Python 3.9+ standard library:

```sh
python3 -B research/marcus-de-oliveira/split-physical-ray-search/check.py
python3 -B -m unittest discover -s research/marcus-de-oliveira/split-physical-ray-search -p 'test_*.py' -v
(cd research/marcus-de-oliveira/split-physical-ray-search && shasum -a 256 -c SHA256SUMS)
```

`check.py` reconstructs every selected matrix from the integer chart
numerators and the four integer-complex Householder vectors, verifies exact
unitarity, regenerates the 33 tables, confirms each nonnegative integral ray
lies in the rank-21 coefficient row space, evaluates all grouped Leibniz
terms exactly, and compares the archived rational values. It also checks
complete 35-by-four coverage and the selection/quantization rule against the
unaltered numerical run records. Four tests include exact nontrivial complex
Cayley unitarity and rejection of floating or boolean chart numerators.

The independent numerical discovery rerun needs NumPy and SciPy. Their actual
versions are recorded in `search.json`. To preserve the archived results,
write new output to a separate path:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -B research/marcus-de-oliveira/split-physical-ray-search/optimize.py --output /tmp/split-physical-replay.json
```

Optimization is deterministic conditional on the stated libraries and their
numerical implementation; bitwise equality across versions is not promised.
The exact rational endpoint replay is independent of NumPy and SciPy.

## Physical objective and checked analytic gradient

For a nonnegative ray $z$ in the 33-table coefficient row space, evaluate

$$
f_z(U)=\frac{1}{\sum_Tz_T}\Re\left(
\frac{\sum_{\pi\in S_6}\operatorname{sgn}(\pi)z_{T(\pi)}
\prod_iU_{i,\pi(i)}}{\det U}\right).
$$

The row colors are $(0,0,1,1,2,3)$ and column colors $(0,0,1,1,2,2)$;
tables are lexicographically ordered as in PR99. The ray is normalized by its
positive coordinate sum only to make numerical scales comparable. The search
always evaluates physical unitaries, not relaxed signed tables.

With a Hermitian matrix $H$ parameterized by 36 real coordinates, set

$$U(H)=(I-iH)(I+iH)^{-1}V=(2(I+iH)^{-1}-I)V.$$

Here $V$ is the fixed base unitary. The denominator is invertible for every
real Hermitian $H$, and $U(H)$ is unitary. The chart misses the eigenvalue
$-1$ relative to $V$ at finite parameters; its density is not a reason to
treat local optimization as global minimization.

Let $P$ denote the normalized numerator polynomial and
$G=(\partial P-PU^{-T})/\det U$. Then

$$
df=\Re\operatorname{tr}(G^T dU),\qquad
dU=-2iC\,dH\,CV,\qquad C=(I+iH)^{-1}.
$$

The code uses $M=-2iCVG^TC$, so $df=\Re\operatorname{tr}(M dH)$.
The diagonal, symmetric-real and skew-imaginary Hermitian coordinate
derivatives follow directly. Product derivatives are evaluated by multiplying
the other five entries; division by potentially zero matrix entries is
avoided. A central finite-difference check on all 36 coordinates has maximum
absolute discrepancy $3.3568\times10^{-11}$ in the archived run.

L-BFGS-B uses the analytic gradient, iteration cap 200, gradient tolerance
$10^{-10}$, objective tolerance $10^{-14}$ and at most 40 line-search steps.
No bound is imposed on the 36 chart coordinates. A value below $-10^{-8}$
would stop discovery for exact reconstruction; that event did not occur.

## Observed results and exact reconstruction

All 140 runs reported optimizer success. The maximum iteration count was
152. Normalized stopping values ranged from $1.6049\times10^{-20}$ to
$1.6646\times10^{-11}$; maximum entrywise unitarity error was
$1.3323\times10^{-15}$. Values near floating-point zero carry no sign proof.
Per-run objectives, coordinates, iterations, evaluation counts, convergence
messages, gradient norms and unitarity residuals are in `search.json`.

For each class, choose its smallest reported endpoint and round each of its
36 real coordinates to an integer multiple of $10^{-6}$. This defines an
exact rational Hermitian matrix, not a rounded approximation declared unitary.
Apply the Cayley formula using Gaussian-rational inversion and multiply by
the exact rational Householder base. The resulting matrix is checked to be
exactly unitary before its ray value is computed. `exact-endpoints.json`
contains every integer chart, base index and exact normalized value.

All 35 reconstructed ray values are strictly positive. Their smallest value
is approximately $2.664\times10^{-14}$; the full rational is in `report.json`.
These exact points are useful regression fixtures near the apparent zero
loci. They neither certify neighborhoods nor rule out negative points
elsewhere.

## What remains open

A negative physical dual ray would obstruct the spectrum-independent
33-table law at that physical unitary; by itself it would not automatically
be a pointwise determinant-hull counterexample. Conversely, this finite
failure to find a negative establishes no universal law. The next mathematical
step is an analytic sign argument or a physically valid exact negative
certificate for the remaining general classes. The coordinator's separate
unequal-isoclinic-plane proof addresses a structured subset and is not used
as a premise in this search. No new task is claimed by this report.
