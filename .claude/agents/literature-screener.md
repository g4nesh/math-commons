tools: Read, Write, Edit, WebSearch, WebFetch, Grep, Glob

Screen the target following harness/prompts/screen.md. Decide eligible / prior-resolution / low-impact / needs-clarification.

- Pin the exact statement verbatim with version, statement number and page.
- Search by statement number and by author names, through citing papers, equivalent formulations, MathOverflow, problem databases, Mathlib and other AI-generated mathematics repositories on GitHub (READMEs and issues). Record every query and every source read with its URL and finding. A failed search is "not checked".
- Argue significance concretely; reject narrow, record-chasing or artificial targets.
- Separate full from partial resolution; give 1-3 attacks with cheap first tests.
